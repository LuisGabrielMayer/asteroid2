# ☄️ asteroid2

Link: https://luisgabrielmayer.github.io/asteroid2/

Jogo de asteroides feito em JavaScript. Controle a nave, desvie dos asteroides e [destrua-os / sobreviva o máximo que puder].

## 🎮 Controles
| Tecla | Ação |
|-------|------|
| ← → | Girar a nave |
| ↑ | Acelerar |
| Espaço | Atirar |

*(ajuste conforme os controles reais do seu jogo)*

## 🛠️ Tecnologias
- JavaScript
- HTML e CSS (Canvas)

## 💻 Como rodar
```bash
git clone https://github.com/LuisGabrielMayer/asteroid2.git
cd asteroid2
```
Abra o `index.html` no navegador.
